# ac_network — 交流正弦稳态相量分析器（纯标准库）

对小型线性交流电路做逐频率的相量（有效值）分析：求解全部节点电位与支路电流，
计算每条支路的复功率，并核对节点电流（KCL）残差与全网络功率收支。

## 运行

```
python -m ac_network 输入.json --out 输出目录
```

- 仅依赖 Python 3.12+ 标准库，无需安装第三方包。
- 输出目录不存在会自动创建。
- 示例：`python -m ac_network examples/rlc_divider.json --out build/out`

退出码：

- `0`：所有频率均求解成功且通过 1e-8 误差核对。
- `1`：电路合法，但至少一个频率无唯一解（浮置网络 / 电源矛盾）或核对失败；
  其他频率照常求解并写出结果。
- `2`：输入电路非法，整批拒绝，**不写出任何结果**。

## 输入格式（JSON，SI 单位）

```json
{
  "name": "可选名称",
  "ground": "g",
  "nodes": ["g", "n1", "n2"],
  "branches": [
    {"id": "r1", "type": "resistor",        "from": "n1", "to": "n2", "r": 4.0},
    {"id": "l1", "type": "inductor",        "from": "n2", "to": "g",  "l": 0.001},
    {"id": "c1", "type": "capacitor",       "from": "n2", "to": "g",  "c": 1e-4},
    {"id": "v1", "type": "voltage_source",  "from": "n1", "to": "g",  "phasor": {"real": 10.0, "imag": 0.0}},
    {"id": "i1", "type": "current_source",  "from": "g",  "to": "n1", "phasor": {"real": 0.5, "imag": 0.2}}
  ],
  "frequencies": [50.0, 200.0]
}
```

约定与校验规则：

- `nodes`：非空、唯一的节点 id 列表；`ground` 必须是其中之一。
- `branches`：支路 id 唯一；`from`/`to` 必须是两个**不同且已存在**的节点。
  支路电压 = `from` 电位 − `to` 电位；电流正方向为 `from → to`。
- 被动元件：电阻 `r`（Ω）、电感 `l`（H）、电容 `c`（F），必须为有限正数。
- 电源：`phasor` 给出有效值相量的有限实部/虚部（电压源单位 V，电流源单位 A）。
  电压源固定支路电压，电流源固定支路电流；均可跨接任意两个非接地节点。
- `frequencies`：有限正频率（Hz），唯一、非空。角频率取 `ω = 2πf`。

## 求解方法

采用改进节点法（MNA）联立方程，对每个频率独立求解：

- 阻抗：电阻 `R`、电感 `jωL`、电容 `1/(jωC)`。
- 未知量为所有非接地节点电位以及每个**电压源的支路电流**。
- 节点行写入 KCL；每个电压源增加一行约束 `V_from − V_to = Vs`，
  因此电压源不会被错误地当作对地电源。
- 电流源的固定电流直接进入方程右端。
- 用带列缩放部分主元的高斯消元（复数运算，纯 Python）求解；
  主元过小即判定无唯一解。浮置网络、矛盾电压源等奇异情形标记该频率失败，
  **不补接地、不加虚构小电阻**，其余频率继续。

## 输出

每个频率生成两个 CSV（SI 单位，数值使用 `repr` 全精度写出）：

- `nodes_f###_<f>hz.csv`：节点电位（实部/虚部/幅值/相位°）与该节点 KCL 电流残差。
- `branches_f###_<f>hz.csv`：每条支路阻抗、电压、电流（实部/虚部）与
  吸收复功率的有功 P（W）和无功 Q（var）。

`summary.json` 汇总电路、每个频率的状态、节点/支路相量、最大功率残差与
总复功率（全部支路吸收功率之和）。

支路吸收复功率：`S = V_branch · I_branch*`，实部为有功，虚部为无功；
负值表示该支路向网络输出功率。

## 核对标准

良态结果须同时满足（绝对误差或相对误差，容差 `1e-8`）：

- 每个节点的 KCL 电流残差 ≤ `1e-8 × max(1, 各支路电流模)`；
- 全部支路吸收复功率之和（源与负载的功率收支差）模值
  ≤ `1e-8 × (1 + Σ|S|)`。

未通过核对的频率在 `summary.json` 标记为 `failed`，进程以非零码退出。

## 测试

```
python -m unittest discover -s tests -v
```

覆盖输入校验、R/L/C 阻抗、跨非接地节点电压源、电流源方向、
多电压源一致/矛盾回路、浮置网络奇异判定、频率相关性以及 CLI 退出码
（失败频率 → 1；非法电路 → 2 且不产生输出目录）。
